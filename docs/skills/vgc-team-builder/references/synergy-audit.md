# Synergy and Matchup Audit

Use this checklist after the six is chosen and before the playbook or export is finalized.

## Audit Table

| Dimension | Question | Result | Fix |
|---|---|---|---|
| Speed control | Does the team have Tailwind, Trick Room, Icy Wind, priority, or another repeatable way to move first? | pass / partial / fail | name the change |
| Trick Room | If the team uses Trick Room, who sets it and who abuses it? If it does not, how does it answer an opposing setter? | pass / partial / fail | name the change |
| Weather | If the team uses weather, who sets it and who abuses it? How does it answer the opposing weather? | pass / partial / fail | name the change |
| Fake Out | Who uses Fake Out, what does it enable, and what happens when the opponent has Covert Cloak or a faster Fake Out? | pass / partial / fail | name the change |
| Endgame | Who is the closer, what is preserved for the endgame, and what happens after the main win condition is removed? | pass / partial / fail | name the change |
| Role overlap | Are two slots doing the same job while another job is missing? | pass / partial / fail | name the change |
| Item and ability overlap | Do two slots depend on the same item, ability, or field condition in a way that breaks the plan? | pass / partial / fail | name the change |
| Support and closer balance | Is there enough support to stabilize without losing the closer? | pass / partial / fail | name the change |

## Output Rules

- State `pass`, `partial`, or `fail` for every dimension.
- Every `partial` or `fail` needs one concrete fix. Do not list a problem without a correction.
- If a dimension does not apply, say why and mark it `pass` only when the team genuinely does not need it.
- Do not turn the audit into a second team. Fixes belong in `Weaknesses and Next Refinements` unless they change the recommended six.

## Common Failure Modes

- Speed control exists on paper but only on a slot that cannot afford to use it.
- Trick Room is listed as a mode but the team has no abuser or no answer to Taunt.
- Weather is listed as a mode but the team loses the weather war and has no backup plan.
- Fake Out is treated as free pressure without naming the follow-up.
- The endgame is "the last mon" instead of a planned closer.
- Two slots cover the same threat while a common core goes unanswered.
- The team has four support slots and no reliable closer.
- The team has six attackers and no way to stabilize the board.
