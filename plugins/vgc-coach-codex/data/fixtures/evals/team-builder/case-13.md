# Case 13

Research expectation: live_required

Request:

`Build a battle-ready Champions team around Mega Venusaur. Use real 2-mon, 3-mon, and 4-mon cores from Limitless and the 4/5/6-mon shells LabMaus publishes. Name the source and date for every core.`

Checks:

- includes `Targeted Meta Cores and Teams`
- names 2-mon, 3-mon, and 4-mon cores counted from Limitless standings or decklists
- names 4-mon, 5-mon, or 6-mon LabMaus shells without pretending LabMaus publishes 2/3-mon cores
- gives a source and date or event for every core
- uses the cores in slot selection, benchmark selection, and matchup framing
- keeps the visible core list to 3 to 5 entries
- does not invent a core, sample size, or source date
- includes `Playbook` packages whose `Use Into` names one of the listed cores

Failure triggers:

- lists a core without a source and date
- invents a 2-mon or 3-mon LabMaus core
- turns the core section into a mini meta report
- uses generic `Use Into` labels instead of the listed cores
